# NetSuite Fast Time Tracker — VS Code extension

Planned: load and log NetSuite hours directly from VS Code.

This package is a placeholder. The NetSuite session lives in the browser, so the
VS Code extension is expected to talk to the Chrome extension in [`../web`](../web)
over a localhost WebSocket bridge instead of authenticating with NetSuite itself.

Nothing is scaffolded yet (no `package.json`, no source).
